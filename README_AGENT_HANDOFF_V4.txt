Почему падал v3

Потому что модель вернула:
- JSON в ```json ... ```
- и после него ещё обычный текст

Обычный json.loads(content) ломался на "Extra data".

Что исправлено в v4:
- вытаскивается первый JSON-объект даже если после него есть текст
- fenced ```json ... ``` тоже поддерживается
- PASS с null-полями больше не роняет скрипт

Запуск:
  python agent_handoff_v4.py --dry-run --sport hockey --limit 5
