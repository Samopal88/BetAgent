source_probe.py — как использовать

1. Положи файл в папку проекта
2. Установи requests, если ещё не установлен:
   pip install requests

3. Запусти:
   python source_probe.py

4. Что получится:
- папка tests_output/
- source_probe_results.json
- по одному HTML-файлу на источник

5. Как понять результат:
- если OK=true -> источник, скорее всего, реально доступен для парсинга
- если FAIL -> либо блокируется, либо отдаёт мусор, либо не содержит нужный контент

6. Что делать дальше:
- открыть tests_output/*.html
- посмотреть, где структура стабильнее
- после этого писать уже конкретный parser/enricher под рабочий источник
