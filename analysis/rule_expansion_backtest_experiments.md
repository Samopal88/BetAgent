# Rule Expansion Backtest Experiments — 2026-04-11

## Sandbox Experiment — NO production changes

This report tests expanded parameter variants for existing rule-driven strategies.
All experiments run against historical `backtest_matches` data.
Production rules are NOT modified.

**Important:** Probability for each rule is estimated empirically from the baseline
variant's historical hit rate on the backtest data. This is then applied uniformly
across all variants of that rule for fair comparison.

**Limitation:** `backtest_matches` does not contain form details, table positions,
or goal averages. Rules that depend on these (DRAW_SA goals/table filters,
BTTS_YES_CORE form filters) are tested with only their odds-range criteria.
This means the backtest is more permissive than live rules.
