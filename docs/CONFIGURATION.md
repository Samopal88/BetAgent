# Настройка BetAgent

BetAgent читает настройки из локального файла `.env`. Шаблон находится в `.env.example`.

## Базовые параметры

| Переменная | Обязательность | Назначение |
|---|---|---|
| `BETAGENT_DB` | рекомендуется | путь к основной SQLite-базе |
| `BETAGENT_DB_PATH` | совместимость | альтернативное имя пути SQLite для старых модулей |
| `BETAGENT_BANK` | да | стартовый аналитический банк |
| `STALE_PENDING_HOURS` | нет | срок, после которого pending считается зависшим |
| `ENABLE_CLV` | нет | включение CLV-трекинга (`0`/`1`) |

## Панель и API

| Переменная | Обязательность | Назначение |
|---|---|---|
| `PANEL_USER` | для панели | имя Basic Auth |
| `PANEL_PASS` | для панели | сильный пароль; генерируется установщиком |
| `API_BASE_URL` | для клиентского бота | URL FastAPI, по умолчанию `http://127.0.0.1:8001` |
| `DATABASE_URL` | для SaaS API | PostgreSQL DSN |
| `JWT_SECRET` | для SaaS API | ключ подписи JWT; генерируется установщиком |
| `JWT_EXPIRE_HOURS` | нет | срок жизни JWT |

## Telegram

| Переменная | Назначение |
|---|---|
| `TELEGRAM_BOT_TOKEN` | административный бот |
| `TELEGRAM_CHAT_ID` | чат администратора |
| `CLIENT_BOT_TOKEN` | клиентский бот подписчиков |
| `CHANNEL_BOT_TOKEN` | бот публикации в канал |
| `CHANNEL_ID` | ID канала, обычно вида `-100...` |

Бота необходимо добавить в канал администратором с правом публикации сообщений.

## LLM

| Переменная | Назначение |
|---|---|
| `LLM_API_URL` | OpenAI-compatible chat completions endpoint |
| `LLM_API_KEY` | API-ключ поставщика |
| `LLM_MODEL` | имя модели у поставщика |

LLM-слой экспериментальный. Не используйте его как единственное основание для решения.

## Источники спортивных данных

`FOOTBALL_DATA_API_KEY`, `API_FOOTBALL_KEY`, `ALLSPORTS_API_KEY`, `ODDS_API_KEY`, `API_KEY` и `FONBET_RESULTS_APIS` требуются только модулям соответствующих поставщиков. Без ключа такой модуль должен быть отключён или будет завершаться с ошибкой, но остальные компоненты могут работать.

## Платежи и почта

- `YOOKASSA_SHOP_ID`, `YOOKASSA_SECRET_KEY` — YooKassa;
- `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASS`, `SMTP_FROM` — email-верификация;
- `PRICE_BASIC`, `PRICE_PRO`, `PRICE_PREMIUM` — цены в рублях.

## Правила безопасности

1. Не коммитьте `.env`.
2. Используйте разные токены для admin, client и channel bots.
3. После случайной публикации не достаточно удалить ключ из Git — его нужно отозвать у поставщика.
4. Не открывайте FastAPI или Flask напрямую в интернет; используйте HTTPS reverse proxy и firewall.
5. Храните резервные копии SQLite и PostgreSQL отдельно от репозитория.
